# Готовые справочники «Лаборатории справочников»

Лента готовых справочников модуля `fivecorners.loadeddirectorylist` (5 УГЛОВ). Модуль раз в сутки читает `index.json` и скачивает справочники, у которых выросла версия.

Адрес оглавления по умолчанию: `https://raw.githubusercontent.com/5corners-ru/ldl-catalogs/main/index.json`. Он задаётся в настройках модуля.

## Формат

`index.json`:

```json
{"format": 1, "catalogs": [
  {"code": "ru_regions", "name": "Регионы России", "description": "…", "version": 1, "file": "ru_regions.json", "sha256": "…"}
]}
```

- `code` — код справочника в модуле: `[a-z][a-z0-9_]{1,49}`. **Не меняется никогда.**
- `version` — целое число. Модуль скачивает файл, только если версия больше той, что у него уже есть.
- `file` — имя файла рядом с оглавлением.
- `sha256` — сумма файла. Проставляет `tools/sign.py`, руками не правится.

`index.json.sig` — подпись ed25519 точных байтов `index.json`. Модуль принимает ленту, только если подпись сходится с одним из ключей, зашитых в него (`tools/public-keys.txt` — их копия), а каждый файл — со своей суммой. Не сошлось — лента отвергается целиком, у клиентов остаются прежние данные.

Файл справочника — формат импорта модуля: `{"columns": [...], "items": [...]}`. У каждой строки есть `code`, по нему модуль сопоставляет строки.

## Правила правки

1. **Строки не удаляются.** Модуль пропавшую строку не удаляет, она просто перестаёт обновляться. Устаревшее значение оставляем в файле.
2. **Код строки не меняется.** Новый код — это новая строка, а старая остаётся в карточках клиентов как была.
3. **Колонки не удаляются и не меняют тип.** Новую колонку добавлять можно.
4. **Любая правка содержимого — `version` + 1** в `index.json`. Без этого клиенты её не получат.
5. **После правки — подписать:** `python tools/sign.py` (нужен `pip install pynacl` и закрытый ключ из BearPass — запись «ldl-catalogs signing key»: в переменной `LDL_CATALOG_SIGNING_KEY` или файлом `~/.ldl-catalogs/signing.key`). Неподписанную правку ловит проверка `check` на PR.
6. Правка — через PR. Если в PR меняется много строк, перед мержем проверить, что источник не отдал мусор.

После подписи скопировать изменённые файлы **и `index.json`** в модуль (`install/catalogs/`) байт в байт: там лежит встроенный снимок на случай, если портал без интернета.

## Источники

| Справочник | Источник |
|---|---|
| `ru_regions` | Перечень и названия — ст. 65 Конституции РФ; коды — справочник ФНС «Коды субъектов РФ» (Приказ ФНС ЕД-7-14/617@ в ред. от 25.07.2025); федеральные округа — Указ Президента РФ от 13.05.2000 № 849 в ред. от 26.06.2023. ДНР, ЛНР, Запорожская и Херсонская области в Указ № 849 не внесены, в Южный округ отнесены по ОКТМО (условно). |
| `ru_holidays` | Ст. 112 ТК РФ; постановление Правительства РФ от 24.09.2025 № 1466 «О переносе выходных дней в 2026 году». Сверено с производственными календарями КонсультантПлюс и assistentus.ru: 247 рабочих дней, норма 1972 ч при 40-часовой неделе. |
